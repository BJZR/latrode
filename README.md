# latrode-deploy

Sitio publicado de Latrode: **https://bjzr.github.io/latrode-deploy/**

Este repositorio lo llena solo el flujo de despliegue de `latrode-src` (GitHub Actions). El código que hay aquí está ofuscado a propósito y **no se edita a mano**: el siguiente despliegue lo reemplazaría.

- Repositorio público con **GitHub Pages** activado (rama `main`, carpeta raíz).
- Para cambiar la página, modifica `latrode-src` y haz push a `main`.
- Para cambiar productos, usa el panel de administrador de la tienda.
